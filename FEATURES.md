# Xander features

## Create custom AI personalities

Xander lets users create chatbots by configuring personality traits and interaction preferences. The creator includes options such as a chatbot name, profile picture, basic personality, relationship to the user, conversational goal, way of thinking, vibe, habits, and speaking style.

## Personalise the experience

The app includes a theme picker. The currently shown themes are:

- Electric Ice
- Galaxy Girl
- Donut Cafe
- Cyber Grape
- Royal Gold
- Neon Matcha
- Sunset Mirage
- Starlight Mist
- Midnight Lava

## Connect AI providers

Current integrations reported by the developer:

- Groq
- Google Gemini
- OpenRouter
- Novita
- Cohere
- Hugging Face
- Mistral

Xander offers temporary API keys for a limited quick-start experience. Users ultimately need to configure their own API key for continued use. Availability, limits, and model access are controlled by the selected provider.

## Accounts and cloud data

- Sign-in uses Google.
- Firebase Realtime Database is used for online chatbot/personality data.
- Chat history is not saved in Firebase.

## Distribution

Xander is distributed as an Android APK. The app's source code is private and is not published in this repository.
