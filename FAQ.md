# Frequently asked questions

### Does Xander require an account?
Yes. Users sign in with Google.

### Which AI providers are supported?
Groq, Google Gemini, OpenRouter, Novita, Cohere, Hugging Face, and Mistral.

### Do I need my own API key?
Xander provides temporary keys for a limited quick-start experience. Users are ultimately expected to configure their own API key. Provider accounts, quotas, and charges are subject to each provider's terms.

### Are chatbot details stored online?
The app uses Firebase Realtime Database for online chatbot/personality data.

### Is chat history saved in Firebase?
No. The developer has confirmed that chat history is not saved in Firebase. This does not establish the data-retention practices of third-party AI providers; consult the provider you choose.

### Is Xander open source?
No. The Android app is currently distributed as an APK; its source code is private and is not included in this repository.

### Where can I download Xander?
Use the latest release on the GitHub Releases page: https://github.com/adityachahal83/Xander/releases/latest
